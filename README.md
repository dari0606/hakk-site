# Hakk Academy — публичный сайт

Самостоятельный сайт для клиентов: витрина академии и подарочная видеотека.
Не зависит от учебной платформы — это отдельный проект и отдельный адрес.

**Статический**: после сборки получается папка `dist/`, которую можно положить
на любой бесплатный хостинг. Нет сервера, нет базы, нечему ломаться и незачем платить.

## Запуск и сборка

```bash
npm install
npm run dev      # http://localhost:5180
npm run build    # готовый сайт в dist/
```

## Подарочные коды

Клиент покупает пробный урок → получает код → открывает все 76 видеоуроков.
Доступ запоминается в браузере, на витрине остаются 4 открытых урока.

```bash
npm run codes -- 20 "Қыркүйек тобы"   # выпустить 20 кодов
npm run build                          # пересобрать сайт
```

Коды хранятся в `data/codes.txt`. Чтобы **отозвать** код — удалите строку и
пересоберите сайт.

### Как устроена защита

Открытыми в `public/gift.json` лежат только витринные уроки. Остальные
зашифрованы (AES-256-GCM), а ключ запечатан каждым кодом отдельно (PBKDF2).
Без кода ссылок на подарочные уроки в файлах сайта нет — проверить можно так:

```bash
grep -c "f7lCH8cGROQ" public/gift.json   # 0 — закрытого урока в файле не видно
```

Чтобы подарок был настоящим, переведите подарочные уроки на YouTube в режим
**«Доступ по ссылке» (Unlisted)**, а 4 витринных оставьте публичными.

## Звук природы

`public/sound/nature.m4a` — тихое пение птиц, 37 секунд, играет по кругу.
Включается кнопкой-динамиком у нижней панели, по умолчанию выключен:
браузеры не дают запускать звук без нажатия, да и навязывать его не стоит.
Выбор запоминается, при уходе на другую вкладку звук ставится на паузу.

Источник: Wikimedia Commons, «Birdsong mild sunny day», общественное достояние.
Заменить — положите свой файл с тем же именем.

## Что где лежит

| Файл | Зачем |
|---|---|
| `src/copy.js` | Все тексты сайта на казахском и русском |
| `src/config.js` | WhatsApp, соцсети, ссылка на платформу |
| `data/lessons.json` | Каталог уроков канала (76 штук) |
| `data/codes.txt` | Выпущенные подарочные коды |
| `public/logo.png` | Логотип (положите свой файл сюда) |

## Обновить уроки после новых загрузок на канал

Открыть плейлист загрузок `youtube.com/playlist?list=UUxOw4gHztFswqyl0ee-vx8w`,
добавить новые уроки в `data/lessons.json` и пересобрать сайт.

## Публикация

Подойдёт любой статический хостинг: Cloudflare Pages, Netlify, Vercel, GitHub Pages.
Самый быстрый способ — перетащить папку `dist/` на app.netlify.com/drop.
Свой домен подключается в настройках хостинга.
